## What I'm working on

### [TL Agent](https://github.com/pouramin/TL-Agent)

A **standalone local coding-agent workspace** built to run outside the IDE — with its own workflow, local UI, project handling, and launcher.

TL Agent currently uses Kilo Code as its underlying agent engine, while the product itself is developed as an independent open-source project.

→ **[Repository](https://github.com/pouramin/TL-Agent)** · **[Documentation](https://pouramin.github.io/TL-Agent/)**
