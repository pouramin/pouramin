## روی چه چیزی کار می‌کنم

### [TL Agent](https://github.com/pouramin/TL-Agent)

یک **محیط مستقل و لوکال برای ایجنت کدنویسی** که خارج از IDE اجرا می‌شود و رابط کاربری، مدیریت پروژه، جریان کاری و لانچر خودش را دارد.

TL Agent در حال حاضر از Kilo Code به‌عنوان موتور ایجنت در لایه زیرین استفاده می‌کند، اما خود محصول به‌صورت یک پروژه مستقل و متن‌باز توسعه داده می‌شود.

← **[مخزن پروژه](https://github.com/pouramin/TL-Agent)** · **[مستندات](https://pouramin.github.io/TL-Agent/)**

## حوزه‌هایی که دنبال می‌کنم

- 🤖 ایجنت‌های کدنویسی هوش مصنوعی، Agent Harnessها و جریان‌های کاری خودکار
- 🔀 مسیریابی مدل‌ها، API Gatewayها و ساختارهای چندمدلی
- 🧰 ابزارهای توسعه‌دهندگی Local-first و اتوماسیون
- 🌐 شبکه، تونلینگ و ابزارهای زیرساختی
- 🧪 آزمایش‌های عملی متن‌باز — ساختن، تست کردن، خراب کردن، درست کردن و مستندسازی
